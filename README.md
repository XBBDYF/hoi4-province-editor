# HOI4 地块细化 / 地图编辑器

把 `provinces.bmp` 里**过大的地块**自动切成若干小块，并在拆分后**自动修复地图系统**
（战略区 / 州归属、铁路、海峡运河）；同时提供一个**浏览器里的地图编辑器**，
可以直接改州(state)、战略区、大洲、地块、铁路/补给、地块地形。

新地块会：
1. 在 `provinces.bmp` 上得到一块新的唯一颜色；
2. 往 `map/definition.csv` 追加一行（**完整复制原地块**的类型/沿海/地形/大洲参数）；
3. 加入原地块所属的 **state**（`history/states/*.txt`）与 **strategic region**（`map/strategicregions/*.txt`）；
4. 拆分后自动**修复铁路断连**（`map/railways.txt`）、**海峡/运河与不可通行**
   （`map/adjacencies.csv`、`map/adjacency_rules.txt`），并校正战略区/州的重复归属。

原地块 **ID 和颜色保持不变**（只是面积变小），所以引用原 ID 的地方
（`supply_nodes.txt`、`buildings.txt`、`victory_points` 等）不会失效。

## Web 界面

**地图预览（主视图）**

- 图层：地形 / 省份色块 / 大洲 / 战略区 / 州 / 边界，可各自开关、调不透明度。
- 交互：滚轮以光标为中心缩放，拖动平移，`适应` / `1:1`；悬停看省份信息；单击选中。
- 右上角**搜索条**：下拉选 **地块 / state / 战略区 / 大洲**，输入编号后按 **精确匹配**
  把**所有命中的地块一起高亮**并缩放到范围（例如选 `state` 输 `50` → 标出属于 50 号州的全部地块）。

**分析**：只读跑一次，列出所有"过大"地块（ID/色块/面积/拆分数/类型/大洲/state/战略区），
点表头排序、点行定位。

**细化**：真正写出结果到输出目录（默认不覆盖原 mod），带实时日志、进度条、
修改前/修改后预览、结果摘要（含修复备注）。

**检查（完整性）**：体检地图系统。结果里 **红色=需要处理**，**黄色=仅供参考、需手动修复**。

- 红：战略区/州重复归属与无效 ID、铁路断连、**地块不连通 / 孤立碎片**、
  **州不连续 / 战略区不连续**（用省份邻接图判断某州/战略区的省份是否连成一片）、十字交叉。
- 黄（⚠ 仅预警，不自动改）：海峡/运河异常、不可通行异常，以及"不可通行条目"计数。
  结果底部会显示**统计来源**（实际读取的 `adjacencies.csv` 路径），方便核对数字。

**编辑**：勾选「编辑模式」后，选图层 + 参考来源，点击地图操作。

| 图层 | 能做什么 |
| --- | --- |
| 州 state | 改归属国/人数/类别/建筑；把地块加入或移出州；**用选中地块新建州** |
| 战略区 | 改名称与 weather 文本；新建战略区 |
| 大洲 | 给地块分配大洲 |
| 地块 prov | 合并（多块并为一块）、删除（并入最大邻居） |
| 铁路 / 补给 | Shift 点两块自动建铁路（**只走陆地**、可跨海峡/运河，遇不可通行会绕开）、改等级、删除；点地块增删补给中心 |
| 地块地形 | 读取 `terrain.bmp` 显示/修改地形，支持一键自动生成、反向导出 `terrain.bmp` |

- **参考**：可选 `mod 原文件` 或 `output 输出`，决定编辑读取哪一份数据。
- 所有编辑都是**先记成操作**（可撤销/重做/重置），点 **导出到输出目录** 才写盘，且**只写改动过的文件**、
  **保持原文件名**。
- **新建时的 ID 规则**：优先**复用空闲 ID**（编号空缺，或文件存在但里面没有地块），
  都没有才用最大编号 +1。新建州/战略区前会用当前数据再核对一次，页面也会实时显示"下一个可用 ID"。

## 参数说明（CLI / GUI 通用）

| 参数 | 说明 |
| --- | --- |
| `--mod` / `--out` | mod 根目录 / 输出目录（默认不覆盖原 mod） |
| `--threshold` | 像素面积上限，超过就细化（默认 200） |
| `--target` | 目标每块面积，`0` 表示用 `threshold`（默认 0）；拆分数 = ⌈面积/目标⌉ |
| `--min-part` | 新地块最小面积，小于它的碎块会并回邻居（默认 80） |
| `--max-parts` | 单块最多切成几份（默认 64） |
| `--scope` | 检测类型：`all` / `land` / `sea` / `lake`（默认 `all`） |
| `--continents` | 只处理这些大洲 ID，逗号分隔（默认 `1,2,3`） |
| `--include` / `--only` / `--exclude` | 强制细化 / 仅处理这些 / 排除（默认排除 `85,69,86,114`） |
| `--gradient` | 渐变密度图；近白区域默认不细化，黑色区域按目标面积细化 |
| `--grad-allow-white` | 关闭"近白区域跳过"规则，恢复原先白色也可按目标面积细化 |
| `--parts` | 指定某块拆成几份，如 `225:4,300:2` |
| `--analyze` | 只分析不写入 |
| `--audit` | 只做完整性检查 |
| `--no-repair` | 关闭拆分后的完整性修复 |
| `--no-canal-complete` | 关闭运河辅助补全 |
| `--railway-hops` | 铁路断点重连允许的最大插入跳数（默认 25） |
| `--keep-invalid` | 保留战略区/州里不存在的省份 ID（默认清除） |
| `--scale` | 预览图缩放（默认 1.0 = 原尺寸） |
| `--seed` | 随机种子（结果可复现） |

## 工作原理

1. 读 `provinces.bmp` 按颜色统计每个地块像素面积；`definition.csv` 把颜色映射到省份 ID。
2. 按规则筛选"过大"地块。
3. 每块用 **KMeans 撒种子 + 多源 BFS(测地线)** 切成 k 个**保证连通**的小块；碎块并回边界接触最多的邻居；
   **面积最大的一块保留原 ID**，其余分配新 ID（从当前最大 ID+1 起）。
4. **完整性修复**（默认开）：
   - **十字交叉边界**：消除 2×2 里的"对角线歧义"，每个交叉只改一个像素且不弄断原省份。
   - **孤立/不连通地块**：一个地块的像素必须 4-连通；多余碎片并到共享边界最长、且不新增交叉的邻居。
   - **战略区/州**：保证每个地块只属于一个，重复归属按"多数邻居所在"判定；不存在的省份 ID 默认清除。
   - **铁路**：`railways.txt` 逐对检查相邻性；断开的用 BFS 插入**陆地**中间地块重连
     （不插到海面/湖泊；跨海靠海峡判定，不会被误改）。
   - **海峡/运河连线**：普通海峡按像素邻接检查并修正被细化的 From/To/Through；运河规则单独按实际河岸像素校准。
   - **不可通行（impassable）**：拆分后把引用旧 ID 的不可通行行**重映射到真正相邻的子块**；
     无法重映射的记入报告，不静默丢失。
   - **沿海属性**：切割沿海地块时，"最大且临海"的那块留给原 ID；新地块 coastal 按其是否临海重算。
5. 渐变密度图：默认黑色目标面积 `80px`、白色目标面积 `250px`；启用白色保护时近白像素不直接切分。
6. 生成预览：**修改前**（目标地块半透明红填充 + 黄描边 + 图例）和**修改后**（新地图 + 白省界）。

## 原版(游戏)目录回退  `--game`

mod 里的地图文件可能不完整（缺 `provinces.bmp` / `rivers.bmp` / `adjacency_rules.txt` / 全量
`history/states/*` 等），这时用 `--game` 指定原版目录补上：

```bat
py -3.13 run_cli.py --mod "C:\...\Project_IRIS" ^
    --game "D:\Program Files (x86)\Steam\steamapps\common\Hearts of Iron IV" ^
    --out "D:\out" --threshold 200 --scope all
```

规则：
1. **单文件**：mod 有就用 mod 的，没有才用原版的（`definition.csv`、`provinces.bmp`、`continent.txt`、
   `rivers.bmp`、`adjacencies.csv`、`railways.txt`、`adjacency_rules.txt`、`terrain.bmp` 等）。
2. **目录（states / strategicregions）**：默认 **mod 有该类文件就只用 mod 的**；完全没有才回退原版。
3. 加 `--game-merge` 则**完全合并** mod 与原版（同名以 mod 为准），等价于 HOI4 的真实加载行为。
4. 输出目录只写**真正改动过**的文件。

GUI 有「原版目录」输入框 +「states/战略区 与原版合并」复选；Web 控制台顶栏有「原版」输入框与同名复选。

## 注意事项

- 默认不修改原 mod，只写输出目录。
- `provinces.bmp` 保持 24 位、同尺寸；末尾填充字节会补齐。
- 新地块继承原地块的地形/大洲/类型；`coastal` 按"是否临海"重算。
- 新地块不会自动获得 `buildings.txt` / `supply_nodes.txt` / 单位堆叠条目（原 ID 的条目仍属于原地块）。
- **大洲别乱选**：给了大洲过滤却选错，会漏拆。
- 拆得太多会让省份总数暴涨，注意 HOI4 对地块总数的引擎上限。
- 检查结果里的**黄色项（海峡/运河/不可通行）仅供参考，需要手动判断修复**。
- `adjacencies.csv` 里本就存在"Through 与两端不相邻"的条目时，工具只报告、不强行改。
- 编辑页的改动在**服务重启或切换路径**后会丢失（未导出的操作不会保存），请及时「导出到输出目录」。
